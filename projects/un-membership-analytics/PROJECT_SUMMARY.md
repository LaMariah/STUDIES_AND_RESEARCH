# Project summary for recruiters

## One sentence

I analyzed a lapsed membership base, built a reactivation funnel, and created a weekly content reporting loop that connected audience data to programming decisions.

## Interview version

The UN Latin Club needed a clearer view of membership retention and content performance. I segmented the member base, identified lapsed members as the strongest reactivation opportunity, and tracked outreach from contact through renewal. I also reviewed weekly content results and translated the findings into recommendations for events and editorial themes. The public repository uses reconstructed aggregate data because the original records are confidential.

## Skills to mention

- Excel and spreadsheet analysis
- Customer lifecycle segmentation
- Funnel and conversion analysis
- Dashboard reporting
- Content performance analysis
- Stakeholder communication
- Data privacy

This repository recreates the analytical structure and aggregate outcomes of the project. It contains no personal information or internal UN data.
