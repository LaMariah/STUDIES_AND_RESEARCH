# Project summary for recruiters

## One sentence

I combined public-source research, Tableau dashboards, data storytelling, content planning, and engagement monitoring in a 120-hour UN-affiliated Latin America project.

## Interview version

The assignment asked a small analytics team to turn research about Latin America and Portuguese-speaking communities into useful content. I built Tableau visualizations, supported an SDG dashboard covering SDGs 4, 5, 10, and 13, researched endangered Indigenous languages using UNESCO and UN public sources, and translated findings into content ideas and reporting. My work connected analysis with communication decisions instead of treating dashboards as an isolated technical output.

## Skills to mention

- Tableau visualization
- Research and source evaluation
- Data storytelling
- SDG analysis
- Content strategy
- Audience and engagement reporting
- Cross-functional collaboration
- Data-quality review
