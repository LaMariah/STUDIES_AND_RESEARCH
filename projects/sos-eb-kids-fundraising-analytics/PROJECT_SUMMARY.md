# Project summary for recruiters

## One sentence

I connected nonprofit storytelling, proposal development, and donor-journey design to a measurement framework for SOS EB Kids.

## Interview version

SOS EB Kids needed fundraising communication that explained a rare condition, built donor trust, and led supporters toward clear actions. I contributed to the fundraising proposal, donor funnel, and web content. I also supported work connected with BrazilFoundation funding. This public project demonstrates how I would measure awareness, trust, donation conversion, stewardship, and institutional funding without exposing donor or beneficiary data.

## Skills to mention

- Digital fundraising
- Proposal development
- Donor journey design
- Nonprofit communications
- KPI definition
- Funnel analysis
- Ethical data handling
