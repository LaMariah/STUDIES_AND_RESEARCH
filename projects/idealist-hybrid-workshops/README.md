# Idealist.org: immigrant entrepreneur workshops

[Read the visual case study](https://lamariah.github.io/STUDIES_AND_RESEARCH/projects/idealist-hybrid-workshops/)

[Read the project management guide](https://lamariah.github.io/STUDIES_AND_RESEARCH/projects/idealist-hybrid-workshops/resources.html)

Gerusa Souza’s work connecting audience research, workshop-topic development, partner coordination, hybrid delivery and participant feedback.

## Delivery flow

Audience needs → workshop scope → partner alignment → hybrid delivery → feedback.

## Project contribution

- Surveys and Facebook discussions informing practical learning topics.
- Workshop content such as “How to sell to Americans.”
- Coordination around the Brazilian Embassy partnership.
- In-person delivery and Zoom breakout participation.
- Post-event surveys asking about useful business connections.

The online guide includes a reusable PM framework alongside the case story.
